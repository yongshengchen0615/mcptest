# ADR-001 — 模擬預約系統架構與 API 契約

狀態：Simulation / Proposed（非正式系統決策）
日期：2026-10-21
關聯：Project #7 / Issue #8

## 決策
- UI：TypeScript 前端元件，使用可測的表單驗證及錯誤狀態。
- API：受控後端 handler，負責 JWT 驗證、輸入驗證、idempotency。
- DB：Supabase PostgreSQL + RLS + transaction/unique constraint。
- 部署：Netlify staging 與 production 環境各連獨立 Supabase project。
- Google Calendar：後續在使用者明確授權後由非同步 outbox worker 處理（本 MVP 不串真實帳號）。

## 資料流程
```text
User Browser (anon/auth)
    | HTTPS + JWT
    v
 API handler -- Auth verify / input validation / requestId
    | transaction
    v
 Supabase PostgreSQL -- reservations/slots/services -- RLS
    |
 outbox worker (mock only) --> External Calendar (not enabled)
```

## 擬議 API 契約
`GET /api/slots?serviceId=svc_demo&date=2026-11-01`
- 200: `{"slots":[{"id":"slot_1","startsAt":"2026-11-01T02:00:00Z","available":1}]}`
- 400: `{"code":"INVALID_DATE"}`
- 404: `{"code":"SERVICE_NOT_FOUND"}`

`POST /api/reservations`
- Header：Authorization: Bearer JWT、Idempotency-Key。
- Body：`{"slotId":"slot_1"}`
- 201: `{"reservationId":"r_demo","status":"confirmed"}`
- 400: `{"code":"INVALID_INPUT"}`
- 401: `{"code":"AUTH_REQUIRED"}`
- 409: `{"code":"SLOT_UNAVAILABLE"}`
- 503: `{"code":"SERVICE_UNAVAILABLE"}`

`GET /api/reservations`
- 200: 只回登入會員的預約陣列
- 401: 未登入
- 絕不接受前端提供其他 `userId` 來擴大存取

## 安全矩陣
| 操作 | 匿名 | 會員本人 | 管理員 |
|---|---|---|---|
| 查公開時段 | 可 | 可 | 可 |
| 建立預約 | 不可 | 可 | 依政策 |
| 查預約清單 | 不可 | 僅本人 | 需另行授權及稽核 |
| RLS/DB migration | 不可 | 不可 | 僅 CI/Migration Service |

## 失敗與補償策略
- API 不可用：顯示重試，避免自動重複建立。
- 409：更新可用時段並提示衝突。
- DB 交易中途失敗：rollback；保留 requestId 供追查。
- Idempotency：同一 key 與同請求在短期內回傳相同結果，key 和 user 綁定。
- Calendar 失敗：可在 outbox 重試，不回滾已確認的預約交易。
- Migration：向前相容、分階段 rollout，破壞性 DDL 必須預先審核。

## 測試策略
- Unit：輸入驗證、時區轉換、狀態映射、冪等性解析。
- Integration：JWT、RLS、DB unique constraint、50 筆併發預約。
- E2E：正常登入→查時段→送出、空列表、雙擊、斷線、手機 UI。
- Security：Unauthorized、跨會員資料、XSS、CSRF/Origin、Token leak、SQL Injection。
- Release：獨立 Staging/Production，smoke + rollback drill。

## 本次模擬限制
沒有真實 API、資料表、Supabase project、Netlify deploy，也沒有量測效能。實際開發前必須建立正式 ADR 與 SQL migration，重新經過 Review。
